# Bank Management System

A complete Bank Management System developed in Python using Object-Oriented Programming (OOP), JSON-based data storage, and Streamlit.

This repository contains two versions of the project:

1. **Original.py** – Original console-based implementation.
2. **Bank.py + app.py** – Optimized version with improved architecture and Streamlit web interface.

---

## Features

### Account Management

* Create Account
* Update Account Details
* Delete Account
* View Account Information

### Banking Operations

* Deposit Money
* Withdraw Money
* Check Account Balance
* View Transaction History

### Validation Features

* Unique Email Validation
* 4-Digit PIN Validation
* Unique 7-Digit Account Number Generation
* Age Verification (18+)

### Data Storage

* JSON-based Database
* Persistent Data Storage
* Automatic Data Updates

## Running the Project

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run Streamlit Application

```bash
streamlit run app.py
```
